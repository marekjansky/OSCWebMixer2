Mixing Desk

On the console, go to Setup > External Control > DiGiCo iPad
Groups add a trim fader to every mix that moves all of the group's channels together, e.g. to turn the whole drum kit down. Assign channels to a group in the Channels tab. Each channel can be in one group.
Webmixer devices can be locked to a single mix with the padlock button in the mixer, so they can't change anyone else's mix. Locks can be changed or removed here.

No ADMIN_PASSWORD is set, so anyone can unlock a device from the mixer and anyone can open this admin area. Set ADMIN_PASSWORD before starting the server to make locks stick.

Presets allow you to save and restore your webmixer config (Auxiliaries, Channels).
